# logic4CS-Math
## Supplementary materials for "Logic for Computer Scientists and Mathematicians"  
By M. Ayala-Rincón, Flávio L. C. de Moura, and T. A. de Lima

This repository includes supplementary materials for the book "Logic for Computer Scientists and Mathematicians"

This book introduces the basis of Applied Logic for Computer Scientists and Mathematicians, focused on the application of logical deductive systems, such as natural deduction and sequent calculus, in the verification and certification of code and in the mechanization of mathematical theorems.
